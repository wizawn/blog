前阵子收拾旧聊天记录，翻着翻着突然觉得，追一个不喜欢你的人，跟打一场毫无胜算的黑盒测试简直一模一样。

## 0x00 以为握手成功就算稳了

刚认识那会儿，来回几句寒暄特别顺，就像刚发出去一个 `Client Hello`，对面秒回 `Server Hello`，紧接着密钥协商走完，通道建起来了。那时候天真地觉得，只要连接是通的，后面迟早能跑起正经业务。

真正往里发包才发现，外层网关的 443 握手看着通了，真往核心内网 `8080` 业务端口探过去，人家早给我的源地址单独挂了一条丢包规则：

```bash
iptables -A INPUT -s $MY_IP -p tcp --dport 8080 -j DROP
```

刚认识时礼貌吃过一回饭，等再试着约第二次，直接石沉大海；拐弯抹角问周末安排，只收到客气又疏远的两三个字。发出去的探测包一个接一个掉进黑洞，偶尔撞上硬邦邦的一句回复，跟抓包窗口里蹦出来的 `RST` 一样干脆。

## 0x01 翻遍了也没有能进的路子

人不死心的时候总爱犯职业病，总觉得是不是自己信息收集没做够。于是去翻她的歌单、看她深夜发的朋友圈、琢磨她喜欢什么口味的奶茶，恨不得做一套完整的目标画像出来。

折腾了一大圈才认清现实：对面根本没有什么配置疏漏，也没有留未授权接口。防线滴水不漏的原因其实特别简单，那套白名单从一开始就没打算把我的地址写进去。

日志其实早就把话说明白了，只是当时装看不见：

```text
[2026-01-15 10:30:00] INFO: 首次聊天，200ms 秒回
[2026-01-20 14:20:00] INFO: 初次约饭，200 OK
[2026-02-01 09:00:00] WARN: 消息回得越来越慢，延迟飙到几个小时
[2026-02-10 16:30:00] ERROR: 整天未读
[2026-02-14 00:00:00] CRIT: 摊牌被拒，403 Forbidden
```

监控告警响了一个月，自己硬把告警静音了而已。

## 0x02 收工，清场

等后来连 `403` 都懒得给、直接甩回来一行资源下线的状态码时，我反倒松了一口气：

```http
HTTP/1.1 404 Not Found
Content-Length: 0
Connection: close
```

干安全这行久了都懂，没拿到授权的目标硬打下去既没结果也不体面。感情里也一样，人家把端口关了，最好的处理就是停掉手里的重放脚本，清掉缓存，老老实实把自己的防火墙规则重新配好，别再把所有鸡蛋全塞进同一个单点故障的节点里。

至于对面，大概早就 `301 Moved Permanently` 去往下一段生活了。把终端关掉，睡觉，明天还得继续看正经日志。
